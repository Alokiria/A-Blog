# 画廊数据（gallery/）

`/albums/` 页面的所有画册都放在这个文件夹里，**一个画册一个文件夹**。
`albums.ts` 会在构建时自动读取这里的所有文件夹，拼成画廊树，所以新增 / 删除画册
都不需要改代码。

> 只想快点加一个画册？复制 `demo-pictures/`（普通画廊）或
> `今天也要阿索拉/`（卡片图鉴）整个文件夹，改名，再改里面的内容就行。

## 目录结构

```
gallery/
├── 今天也要阿索拉/                  ← 一个画册 = 一个文件夹
│   ├── album.ts                   ← 画册信息（id / cover / caption / desc）
│   └── cards.ts                   ← 卡片图鉴数据
├── demo-pictures/
│   ├── album.ts
│   └── photos.ts                  ← 普通画廊数据
└── demo-group/                    ← 里面有子文件夹 = 画廊分组
    ├── album.ts
    ├── demo-group-1/
    │   ├── album.ts
    │   └── cards.ts
    └── demo-group-2/
        ├── album.ts
        └── photos.ts
```

一个画册文件夹里只认这三个文件名，其它文件（草稿、说明、素材）会被忽略，随便放：

| 文件名 | 是否必须 | 作用 |
| --- | --- | --- |
| `album.ts` | ✅ 建议有 | 画册信息：`id` / `cover` / `caption` / `desc` / `order` |
| `cards.ts` | 可选 | 卡片图鉴数据（有搜索框 + 标签筛选，图片下方写名字） |
| `photos.ts` | 可选 | 普通画廊数据（纯图片网格，点开看大图） |
| 子文件夹 | 可选 | 每个子文件夹都是一个子画廊 → 这个画册变成「画廊分组」 |

## 新建一个画册

1. 在 `gallery/` 里新建文件夹，名字建议直接写成你要用的 id（例如 `my-album`）。
2. 在里面写 `album.ts`：

```ts
import type { AlbumMeta } from '~/albums'

export default {
  id: 'my-album',              // 唯一 id，就是网址里的 ?a=my-album，建议和文件夹同名
  cover: 'https://.../cover.jpg', // 封面图
  caption: '我的画册',           // 卡片下方显示的名字
  desc: '随便写点介绍',           // 鼠标悬停时的提示（可省）
  order: 1,                    // 越小越靠前（可省，默认 0）
} satisfies AlbumMeta
```

3. 按画册类型再放一个数据文件（也可以什么都不放，先建个空画册）：

- **卡片图鉴** → `cards.ts`

```ts
import type { AlbumCard } from '~/albums'

export default [
  {
    src: 'https://.../01.jpg',       // 点开大图看到的那张（原图）
    cover: 'https://.../01_s.jpg',   // 网格里显示的小图（可省，不写就用 src）
    name: '卡图 01',                  // 图片下方显示的名字
    meta: '2026/02/01',              // 名字下面一行小字（可省）
    desc: '点开大图后显示在图片下方',   // 可省
    tags: ['游戏A', 'SSR'],           // 搜索会一起匹配（可省）
  },
] satisfies AlbumCard[]
```

- **普通画廊** → `photos.ts`

```ts
import type { AlbumPhoto } from '~/albums'

export default [
  {
    src: 'https://.../01.jpg',       // 点开大图看到的那张（原图）
    cover: 'https://.../01_s.jpg',   // 网格里显示的小图（可省，不写就用 src）
    name: 'IMG_001',                 // 图片下方不显示，用于搜索、悬停提示和大图标题
    desc: '简介',                     // 可省
    tags: ['好看'],                   // 可省
  },
] satisfies AlbumPhoto[]
```

保存后页面就会自动出现这个画册（`npm run dev` 时会自动刷新）。

## 画廊分组（画廊里套画廊）

只要画册文件夹里有子文件夹，它就是一个「画廊分组」，子文件夹按各自的 `album.ts`
变成子画廊，嵌套层数不限：

```
gallery/2026-秋-新番/
├── album.ts          ← 父级的 id / cover / caption / desc
├── 人物设定/
│   ├── album.ts
│   └── cards.ts
└── 场景图/
    ├── album.ts
    └── photos.ts
```

卡片右下角的「N 张」角标是自动统计的（分组会把子画廊的张数一起累加），
不需要手写。

中间层的分组文件夹**可以不放 `album.ts`**（比如只是想把画册分个类）：那就用文件夹名
当分组名，封面自动借第一个子画廊的封面。当然写上 `album.ts` 会更好看。

## 临时下线一个画册

文件夹或文件名以 `_` 开头的会被整个忽略（连打包都不会进），所以：

- 想暂时藏起一个画册 → 把文件夹改名成 `_旧画册`（数据不用删，改回来就恢复）
- 还没写完的草稿画册 → 直接叫 `_draft`

## 字段与规则

### `album.ts`（`AlbumMeta`）

| 字段 | 说明 |
| --- | --- |
| `id` | 唯一 id，网址 `?a=<id>` 用它。不写就用文件夹名 |
| `cover` | 封面图。不写就用这个画册 `cards.ts` / `photos.ts` 的第一张图（分组则用第一个子画廊的封面） |
| `caption` | 卡片下方显示的名字。不写就用文件夹名 |
| `desc` | 悬停提示、进入画册后标题下面的一行小字 |
| `order` | 同级排序权重，越小越靠前；不写按 `0` 算，同权重按文件夹名排序 |
| `cards` / `photos` | 懒得拆文件时，可以直接在 `album.ts` 里写数组（两处都写以 `album.ts` 为准） |

### 排序

同级画册先比 `order`，再比文件夹名。想固定顺序就给每个画册写 `order`：
`order: 1, 2, 3…`（也可以写负数插到最前面）。

> 这里刻意用文件夹名的字符顺序，而不是拼音 / 本地化排序 ——
> 本地化排序在 Node（生成静态站时）和浏览器里的结果可能不一样，会造成页面闪烁。

### 卡片 / 照片的 `cover`（缩略图）

每张卡片 / 照片都可以单独写 `cover`，用来「列表看小图、点开看原图」：

| 字段 | 说明 |
| --- | --- |
| `src` | 点开大图后看到的那张图（原图），「查看原图」链接也指向它 |
| `cover` | 网格里显示的小图。**不写就用 `src` 自己当封面**（和以前完全一样） |

典型的用法是网格用小图省流量、点开才是大图：

```ts
{ src: 'https://图床/o_原图.jpg', cover: 'https://图床/t_小图.jpg', name: '……' }
```

`cover` 加载失败（404、图床防盗链）时会自动退回 `src`，两个都失败才显示占位图标。
画册自己的 `cover` 同理：不写就借这个画册第一张图的 `cover`（没有则用它的 `src`）。

### 大图缩放（灯箱）

点开大图之后：

- **滚轮缩放**（以鼠标位置为中心）、**手机双指捏合**（以双指中点为中心）、**双击**放大 / 还原；放大后可以拖动查看。
- **不限死上限**，想放到多大都行（单次最多放大 1.5 倍，防止惯性甩动一步甩飞）。
- 放大后按钮写的是 `倍率 · 重置`（例如 `171% · 重置`），点一下回到适应窗口。
- 那个倍率是**相对原图尺寸**算的：一张 4000px 宽的图在 1x（适应窗口）时其实只用到 25% 的原图像素，
  放到 `100%` 就是 `1 个原图像素 = 1 个屏幕像素`，此时细节最多；超过 100% 就是插值放大，
  鼠标悬停在按钮上会写明「已超过原图分辨率」。
- 想让缩放按倍数封顶（比如最多 8 倍），给 `useAlbumZoom` 传 `max` 即可，
  见 [album-zoom.ts](../composables/album-zoom.ts)。

### 图片地址

`src` / `cover` 都填**图片 URL**（图床、图链都行）。如果要用本地图片，
把它放进项目根目录的 `public/`，然后写成 `/图片名.jpg`；
`gallery/` 里只放数据文件，放这儿的图片不会被打包发布。

## 容易踩的坑

- **id 不能重复**：重复的话 `?a=<id>` 只会打开其中一个。构建日志里会打印
  `[albums] id「xxx」重复：…` 警告。
- **名字别以 `_` 开头**：那是「忽略」标记，文件夹会直接从画廊里消失（这是故意的）。
- **一个画册只渲染一种视图**：同时有子文件夹和 `cards.ts` / `photos.ts` 时，
  只显示子画廊（分组优先）。构建日志里同样会有提示。
- **没写 `cover` 又没有图片**：构建日志会提示，页面上封面会显示占位图标。
